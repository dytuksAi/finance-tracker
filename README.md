# Finance Tracker

Personal single-page app. All data in `index.html` is encrypted (AES-256-GCM, key from PBKDF2-SHA256 with 600k iterations). It decrypts in the browser after you enter the PIN or use Face ID (WebAuthn PRF).

Includes Home Screen icons and a web manifest.

Live: https://dytuksai.github.io/finance-tracker/
